## 🏠 個人開発

### 賃貸入居者サポートアプリ

賃貸住宅の入居者と管理会社のやり取りをサポートするWebアプリを開発しています。

契約内容の確認や各種申請などをWeb上で行えるサービスを想定し、
**管理者・入居者の権限を分けたWebアプリケーション**として設計・実装を進めています。

主な学習・実装内容：

* ユーザー認証
* 管理者・入居者の権限分岐
* Middlewareによるアクセス制御
* ダッシュボード
* データベース設計
* CRUD処理
* Laravelを使ったMVC構成
* Git / GitHubを使ったバージョン管理
